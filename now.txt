# The Real Industry Trick: Consolidation

Cross-border companies survive because they:

```text id="x5z0ry"
combine many shipments into one bulk freight movement
```

instead of shipping every order individually.

Example:

Instead of:

```text id="sqyxk8"
1 package → Lagos via DHL
```

they do:

```text id="djvccr"
200 packages → cargo pallet → Lagos
```

then local dispatch.

That changes shipping economics massively.

# Better Pricing Architecture

Instead of:

```text id="f2n1mx"
service fee = 20% of everything
```

do:

```text id="chj7fz"
service fee = percentage of product subtotal only
```

Example:

```text id="f3xg1w"
20% × $128
= $25.6
```

NOT:

```text id="k9yq2d"
20% × $300+
```

## Customs

Use category heuristics.

Example:

| Category    | Customs Estimate |
| ----------- | ---------------- |
| Fashion     | 8–15%            |
| Sneakers    | 10–18%           |
| Electronics | 15–30%           |

Avoid exact “government calculator” modeling early.
